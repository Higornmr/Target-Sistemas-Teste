Sobre o Projeto

Olá! Eu me chamo Higor e agradeço a oportunidade de mostrar meus conhecimentos através deste teste. Este projeto foi desenvolvido utilizando JavaScript, HTML, e CSS para proporcionar uma interface visual agradável e funcional.

Como Rodar o Projeto

Para rodar este projeto em sua máquina, siga os passos abaixo:

Clone o repositório:

git clone https://github.com/Higornmr/Target-Sistemas-Teste.git

Abra o projeto em um editor de sua preferência (como VS Code).

Execute o projeto localmente:

Certifique-se de ter a extensão Live Server instalada no editor.

Clique com o botão direito no arquivo index.html e selecione a opção "Open with Live Server".

Funcionalidade

O projeto possui botões interativos localizados abaixo de cada técnica descrita. Ao clicar em um botão, o resultado correspondente à técnica será exibido na tela.
